# saeed tools — فرانت (مرحله ۱)

نسخه‌ی اول سایت با داده‌ی نمونه (بدون بک‌اند).

## اجرا در VS Code
1. پوشه‌ی `saeed-tools` را در VS Code باز کن.
2. افزونه‌ی **Live Server** را نصب کن.
3. روی `index.html` راست‌کلیک کن و **Open with Live Server** را بزن.

## ساختار
- `index.html` صفحه‌ی اصلی
- `products.html` لیست محصولات (با فیلتر دسته‌بندی)
- `product.html?id=1` جزئیات محصول
- `cart.html` سبد خرید
- `checkout.html` ثبت سفارش
- `contact.html` تماس با ما
- `js/data.js` اطلاعات فروشگاه، دسته‌بندی‌ها و محصولات نمونه
- `js/app.js` منطق مشترک (هدر، فوتر، سبد خرید، صفحات)
- `css/style.css` استایل سایت (رنگ اصلی: زرد)

## نکات
- عکس مغازه: فایل `images/shop.jpg` را اضافه کن.
- عکس محصولات: در `js/data.js` فیلد `image` را با مسیر عکس پر کن (مثلاً `images/drill.jpg`).
- سبد خرید فعلاً در localStorage مرورگر ذخیره می‌شود و سفارش‌ها هنوز به جایی ارسال نمی‌شوند؛ این بخش در مرحله‌ی بک‌اند وصل می‌شود.
